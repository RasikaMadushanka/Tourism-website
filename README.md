🌴✨ Sri Lanka Tourism Website ✨🌴








A complete tourism guide to Sri Lanka 🇱🇰, showcasing its breathtaking waterfalls, ancient landmarks, cultural sites, camping spots, and detailed ticket information.
This project is built to inspire travelers and help them plan unforgettable journeys across the island. 🌍✈️

🏝️ Why This Project?

Sri Lanka is often called the Pearl of the Indian Ocean. This website is designed to:

✔️ Promote Sri Lanka’s natural beauty and heritage
✔️ Provide useful travel info (locations, ticket prices, maps)
✔️ Highlight hidden gems like waterfalls & eco-tourism sites
✔️ Offer a modern, responsive design for travelers on any device

✨ Key Features

🗺️ Tourist Destinations – Historical, cultural, and natural wonders (Sigiriya, Temple of the Tooth, Nallur Kovil, etc.)

🌊 Waterfalls Explorer – Discover Duwili Ella, Surathali Ella, Kirindi Ella & more with locations + maps

🏕️ Camping & Eco Tourism – Best places for adventure lovers

🎟️ Ticket Prices – Updated entry fees for main attractions

📸 Image Galleries – Stunning visuals for each location

📱 Responsive Design – Works smoothly on mobile, tablet & desktop

⚡ Lightweight Performance – Optimized code for fast loading
